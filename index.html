Haritada bir noktaya tıklayın. Formasyonun yaşı, litolojisi, tektonik birimi ve paftanın stratigrafik dizilimi burada görünür.
Stratigrafik dikme kesit ·

Lejant sırası (genç → yaşlı). ● seçilen birim; ▲/▼ seçilen poligonun haritadaki sınır komşusu olan genç/yaşlı birimler. Kalınlıklar ölçekli değildir.

Bir birime tıklayınca haritada yalnız o birim vurgulanır; yeniden tıklayınca vurgu kalkar.

Altlık
Google API anahtarı

Google altlıkları, Google'ın resmî Map Tiles API'si üzerinden sizin Google Maps Platform API anahtarınızla açılır (Google Cloud Console → “Map Tiles API”yi etkinleştirip anahtar oluşturun; aylık ücretsiz kullanım kotası vardır). Anahtar yalnızca bu tarayıcıda saklanır.

Kendi dosyalarınız

KML, KMZ (Google Earth), GeoJSON veya GPX dosyasını “KML yükle” düğmesiyle seçin ya da haritanın üzerine sürükleyip bırakın. Dosya yalnızca tarayıcınızda açılır, hiçbir yere gönderilmez.
